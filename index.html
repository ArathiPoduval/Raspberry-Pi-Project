Project Metrics

Stage 1: Dataset Creation (`01_dataset_creator.py`)

Purpose: To capture 30 grayscale images of the user's face to create the training data. This data is the foundation for our recognition model.

Key Logic:

  • Initializes `Picamera2` for the camera feed and loads a Haar Cascade classifier for face detection.
  • Saves cropped face images to the `dataset/1/` folder.
# Run this first to collect images (look at the camera when running)
python3 01_dataset_creator.py

Stage 2: Model Training (`02_trainer.py`)

Purpose: To train the LBPH recognizer using the collected images and serialize the model for real-time use.

Key Logic:

  • Reads all images from the `dataset` folder and extracts the user ID.
  • Trains the LBPH recognizer using OpenCV's `cv2.face.LBPHFaceRecognizer_create()`.
  • Saves the trained model to the file `trainer.yml`.
# Run this second, after collecting the dataset
python3 02_trainer.py

Stage 3: Real-Time Recognition & Control (`03_face_recognizer.py`)

Purpose: The main operational script. It loads the trained model, runs real-time recognition, and controls the servo based on the results.

Key Logic & Servo Control:

  • Initializes RPi.GPIO and starts the PWM signal for the servo at the **Locked** position (2.5% duty cycle).
  • Uses `recognizer.predict()` for real-time face matching.
  • **Match Found:** Servo moves to the **Unlocked** position (12.5% duty cycle).
  • **Match Lost/Unknown:** Servo moves back to the **Locked** position.
# Run this last to start the live system
python3 03_face_recognizer.py

Day 1: RPi OS Installation and RealVNC Setup

Objective: Install the operating system and configure RealVNC for remote desktop access.

1. Install Raspberry Pi OS using Imager:

  • Download and install the Raspberry Pi Imager.
  • Select **Raspberry Pi OS**, choose storage, and set up your **username, password, and Wi-Fi**.
  • Click "Write" to complete the process.

2. Enable RealVNC Server:

Go to **Menu > Preferences > Raspberry Pi Configuration**, select the **Interfaces** tab, and ensure **VNC is set to Enabled**.

3. Connect Remotely:

Use **RealVNC Viewer** on your remote computer and enter your Raspberry Pi's address (`raspberrypi.local` or IP) to connect.

Day 2 & 3: Sensors and Motor Control

Day 2 Objective: Interface and write Python code to read input from a Passive Infrared (PIR) motion sensor.

PIR Sensor Wiring:

  • PIR VCC $\rightarrow$ Raspberry Pi **5V Pin**
  • PIR GND $\rightarrow$ Raspberry Pi **GND Pin**
  • PIR OUT (Signal) $\rightarrow$ **GPIO 17** (Physical Pin 11, BCM)

Day 3 Objective: Control both a Servo Motor (using PWM) and a Stepper Motor (using a driver board).

Servo Motor Control & Wiring:

  • Servo motors use **PWM** (Pulse Width Modulation) to set the angle.
  • Servo Power $\rightarrow$ **5V** (External Supply Recommended)
  • Servo Ground $\rightarrow$ **Common GND**
  • Servo Signal $\rightarrow$ **GPIO 18** (Physical Pin 12)

Stepper Motor Control & Wiring:

  • Stepper motors require an **ULN2003 Driver Board** to sequence the coils.
  • Driver board VCC/GND $\rightarrow$ **External 5V Power** and **Common GND**.
  • Driver board IN1-IN4 $\rightarrow$ **4 GPIO Output Pins** (e.g., GPIO 5, 6, 13, 19).

Auxiliary Code Examples

These are the additional Python scripts referenced in your documentation for interfacing with other sensors and testing OpenCV.

PIR Motion Sensor (Using RPi.GPIO)

Detects movement and prints a message to the console.

import RPi.GPIO as GPIO
import time
PIR_PIN = 17
GPIO.setmode(GPIO.BCM)
GPIO.setup(PIR_PIN, GPIO.IN)

try:
    while True:
        if GPIO.input(PIR_PIN):
            print("Motion Detected!")
        else:
            print("No Motion")
        time.sleep(0.5)
except KeyboardInterrupt:
    GPIO.cleanup()

Servo Motor Control (Using gpiozero)

Alternative servo control script that sweeps the motor between min and max angles.

from gpiozero import Servo
from time import sleep

servo = Servo(18) # Uses BCM 18

try:
    while True:
        servo.min() # e.g., 0 degrees
        sleep(1)
        servo.max() # e.g., 180 degrees
        sleep(1)
except KeyboardInterrupt:
    pass

Basic OpenCV Test (Image to Grayscale)

Loads a file named `image.jpg`, converts it, and displays both windows.

import cv2

img = cv2.imread('image.jpg')

if img is not None:
    gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    
    cv2.imshow('Original Image', img)
    cv2.imshow('Grayscale Image', gray_img)
    
    cv2.waitKey(0)
    cv2.destroyAllWindows()
else:
    print("Error: Could not read image.jpg")
